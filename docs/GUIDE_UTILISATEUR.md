# Guide utilisateur — Food Trucks

## Voir les foodtrucks du jour

Ouvrez le site : les foodtrucks présents **aujourd'hui** s'affichent directement.
Le samedi et le dimanche, ce sont ceux du lundi.

Pour un autre jour, cliquez sur **Lundi**, **Mardi**, **Mercredi**, **Jeudi** ou **Vendredi**.
Le point vert indique le jour d'aujourd'hui.

Pour chaque foodtruck :

- **Nom** : s'il est souligné, un clic ouvre son site (menu, tarifs…) ;
- **Cuisine** : le type de cuisine ;
- **Voir sur Google Maps** : ouvre l'emplacement exact, pour s'y rendre ;
- **Prix** : prix indicatif d'un repas.

## Trier la liste

Cliquez sur le titre d'une colonne (Nom, Cuisine, Prix…) pour trier ; cliquez une deuxième fois pour inverser.
Par exemple, trier par **Prix** met les moins chers en premier.

## Proposer un foodtruck

Vous connaissez un foodtruck qui manque ?

1. Cliquez sur **Suggérer un foodtruck**.
2. Remplissez le nom, le type de cuisine, cochez les jours de présence et collez le lien Google Maps
   (dans Google Maps : « Partager » puis « Copier le lien »). Le prix et le site sont facultatifs.
3. Cliquez sur **Envoyer**.

Votre proposition apparaîtra sur le site après vérification par un administrateur.
Si un champ est mal rempli, un message en rouge explique quoi corriger.

## Signaler une erreur

Un foodtruck n'est plus là, a changé de jour ou de place ? Cliquez sur **Envoyez-moi un mail** en bas de page.

## Sur téléphone

Le site s'utilise aussi sur téléphone : chaque foodtruck s'affiche sous forme de fiche.
